# 10-laboratorios — Laboratórios Práticos de Engenharia de Plataforma

Ambientes hands-on demonstrando a montagem de um ecossistema de plataforma.

## 📂 Subáreas
- [`idp-local-com-backstage/`](./idp-local-com-backstage) — **Stack:** `Subindo o Backstage local com Docker` — Deploy e configuração do portal de desenvolvedor com software templates.
- [`gitops-com-argocd/`](./gitops-com-argocd) — **Stack:** `Deploy automatizado de aplicação via ArgoCD` — Configuração de sincronização GitOps a partir de um repositório de manifesto.
- [`crossplane-k8s-infra/`](./crossplane-k8s-infra) — **Stack:** `Crossplane provisionando recursos cloud via K8s` — Tratamento de infraestrutura externa (bancos, S3) como recursos nativos do cluster.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Platform-Engineering.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.
