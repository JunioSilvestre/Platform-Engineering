# 05-developer-experience — Developer Experience (DevEx) & Golden Paths

Redução da carga cognitiva dos desenvolvedores criando caminhos pavimentados (Golden Paths) e templates.

## 📂 Subáreas
- [`golden-paths/`](./golden-paths) — **Stack:** `Caminhos recomendados com menor atrito e maior segurança` — Guias homologados para que novos serviços cheguem a produção em minutos com conformidade.
- [`templates/`](./templates) — **Stack:** `Boilerplates de serviços com CI/CD, lint e Docker` — Projetos de partida padronizados (FastAPI, Node.js, Go) com telemetria já integrada.
- [`documentacao/`](./documentacao) — **Stack:** `Docs-like-code, TechDocs no Backstage` — Documentação técnica mantida junto ao código em Markdown e renderizada centralizadamente.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Platform-Engineering.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.
