# 01-internal-developer-platform — Internal Developer Platform (IDP) & Arquitetura

Fundamentos da engenharia de plataforma, separação entre plataforma e produto, autosserviço e planos de controle.

## 📂 Subáreas
- [`arquitetura/`](./arquitetura) — **Stack:** `Control plane, Data plane, interfaces de autosserviço` — Desenho conceitual de plataformas que escalam o fluxo de desenvolvimento sem gargalos operacionais.
- [`portal-desenvolvedor/`](./portal-desenvolvedor) — **Stack:** `Service Catalog, painel unificado de ferramentas` — Interface centralizada onde times encontram documentação, serviços e estados de infraestrutura.
- [`autosservico/`](./autosservico) — **Stack:** `Provisionamento sob demanda via formulários ou APIs` — Capacidade dos desenvolvedores criarem bancos de dados, filas e ambientes sem abrir tickets.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Platform-Engineering.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.
