# gestao-secrets

> Sincronização segura de segredos entre cofres corporativos e pods do Kubernetes.

## 🛠️ Tecnologias & Componentes
- `HashiCorp Vault, External Secrets Operator (ESO)`

## 📋 Boas Práticas e Padrões de Produção
- Mantenha configurações desacopladas e declarativas.
- Nunca versione senhas, chaves privadas ou tokens em texto puro.
- Siga as diretrizes de padronização corporativa do módulo [`07-seguranca-e-governanca`](../).
